# THE NEXUS — Healthcare Analytics Portfolio

**Medicine × Data × Business**  
*Turning Healthcare Data into Better Decisions.*

A personal portfolio by **Moutaz Eloraby**, built to present healthcare analytics case studies, analytical workflows, and decision-focused findings.

## Portfolio projects

1. Hospital Operations & Capacity
2. Diabetes Care Quality
3. CKD Monitoring
4. Clinical Trial & RCT Analysis
5. Readmission & Patient Safety
6. Healthcare Financial Performance

Each project has its own page and a README. Links to YouTube videos, Python notebooks, SQL files, presentations and Power BI dashboards will be added as each project is completed. No analytical results are claimed before verification.

## Website

This repository hosts a static site via GitHub Pages. Site design follows THE NEXUS brand identity:
- Primary Navy: `#0B1E3A`
- Data Blue: `#00A3FF`
- Health Teal: `#00D1C1`
- Growth Green: `#A3E635`
- Insight Gold: `#FFD166`
- Fonts: Montserrat / Inter

**Publish:** GitHub repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

Expected public URL after publishing: https://moutaz-o.github.io/The-Nexus/

## Updating project content

Project pages are in `projects/<slug>/`. The central project catalog and resource links are configured in `assets/site.js`. Update those values when actual deliverables have been uploaded and verified.

Only publish data and dashboards that are approved for public sharing. `Publish to web` Power BI reports are public; never expose identifiable patient or confidential organizational data.
